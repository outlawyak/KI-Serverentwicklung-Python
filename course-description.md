- Course code: I Wkis
- Lecturer: Prof. Dr. Jürgen Zimmermann
- Language of instruction: German
- Workload: 2 ECTS, 2 SWS (weekly contact hours per semester)
- Graded assessment: PA/1S (likely a project assignment)
- Ungraded coursework: Ue/1S (likely exercises)

## Core Idea
Software is now developed with AI agents, but responsibility for the code
remains with the development team. Solid knowledge of platforms and frameworks
is therefore still essential. The course first teaches the fundamentals of a
platform and then has students build a server prototype using AI agents.

## Learning Objectives
- Become familiar with three common server platforms: Python,
  TypeScript/JavaScript, and Java
- Build a small server prototype on each platform using AI agents
- Be able to evaluate and take responsibility for AI-generated code

## Structure (repeated for each platform)
1. 3 lectures: introduction to the platform, including database access and
   authentication via OIDC or OAuth2
2. 1 double session: small prototype project using AI tools
